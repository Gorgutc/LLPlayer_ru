# Skill Map

- `llplayer-bootstrap`: start-of-session repository context.
- `llplayer-rules`: repo-wide rules from `AGENTS.md`.
- `llplayer-product-contract`: frozen product/design/runtime/config contracts.
- `llplayer-dotnet-rules`: C#/XAML/project changes.
- `llplayer-context-keeper`: small read-only context gathering.
- `llplayer-spec-guardian`: scope and requirement review.
- `llplayer-frozen-decisions`: protected stack/package decisions.
- `llplayer-quality-gate`: choose verification gate.
- `llplayer-quality-tooling`: scripts, hooks, CI, analyzer policy.
- `llplayer-deadwood-reuse-audit`: duplication and dead code audit.
- `llplayer-instruction-drift`: docs/skills/hooks consistency.
- `llplayer-ship`: commit/push/PR/release handoff.
- `llplayer-runtime-assets`: native binaries, models, runtime files.
- `llplayer-packaging-release`: publish and release packaging.
- `llplayer-wpf-xaml-review`: WPF UI review.
