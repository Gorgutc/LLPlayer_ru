## Global constraints

- Geometry additionally satisfies `SeekBarTrackHeight <= SeekBarThumbHeight <= SeekBarHeight`. Raw invalid drafts remain visible and block Save; finite/range/cross-field checks precede persistence. Loaded invalid values normalize safely without rewriting the file during load.
- Save fresh-merges these owned fields into current preferences, persists before live apply, and preserves unrelated concurrent values. Failed persistence preserves disk/live state and the retry draft; Close/Escape discards edits.
- With hover-only off, retain existing fullscreen + playing + no seeking + closed word-popup idle semantics, including cursor behavior. Configurable timeout replaces the fixed 2.5 seconds; `ActivityTimeoutMs=0` applies immediately when those idle conditions hold, matching WPF `Activity.cs:118–124`. Independent fade durations replace the fixed 200 ms transition; either fade value `0` means an immediate transition in that direction.
- Hover-only uses a stable transport hit region even while visuals are hidden. Pointer-over, transport keyboard focus and popup ownership preserve access; keyboard activity can reveal controls. Expose `SetTransportPointerOver(bool)`, `SetTransportFocusWithin(bool)`, `SetTransportPopupOpen(bool)` and `NotifyKeyboardActivity()` on `MainWindowViewModel` for the shared window.
- Apply `AlwaysOnTop` through Avalonia `Window.Topmost`, on startup and successful Save. Mouse switches gate only their intended video gestures; preserve popup closing, word/drag/selection/control ownership, immediate first-click behavior and the existing second-tap playback rule.
- WPF, engine/Core, dependencies and package topology retain their contracts. Full command-palette/help execution and other unported Settings remain in the existing backlog. The current help is keyboard-only; this block adds no Mouse help tab or cheat-sheet expansion.
- Native Windows/Linux GUI, physical A/V/input, models/providers/GPU/DPI and literal Desktop-click acceptance remain `NOT_RUN / DEFERRED BY OWNER`; automated checks do not grant native acceptance or full F-13 parity.

## Review focus

1. Old/malformed preferences and invalid numeric text: defaults stay compatible; invalid drafts cannot save.
2. Unrelated autosaves during an open draft and persistence failure: fresh values and all live owners survive.
3. Hidden transport, focus, popups, seek capture and rapid activity/fade reversal: controls remain reachable without disturbing classic idle behavior.
4. Nested subtitle/popup/toolbar input and each disabled mouse switch: one gesture causes only the admitted action.
5. Startup, successful Save, discard and fullscreen transitions: geometry/fades/Topmost apply only from committed preferences on both hosts.
