# Plan Template

Use this shape for LLPlayer implementation plans.

```markdown
# Title

## Summary
- What changes.
- What does not change.

## Key Changes
- Files or subsystems.
- Interfaces or commands.

## Verification
- Fast gate, full gate, or ship gate.
- Manual smoke checks if app/runtime behavior changes.

## Assumptions
- Windows/.NET/packaging constraints.
- Any deferred risks.
```

Plans that touch product code must state whether UI, media runtime, native assets, or release packaging are affected.
